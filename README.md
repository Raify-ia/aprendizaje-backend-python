# Aprendizaje Backend Python 🐍

Repositorio de aprendizaje y práctica enfocado en el desarrollo backend con Python, Django, Django REST Framework y fundamentos relacionados con el desarrollo web full stack.

Este repositorio reúne diferentes ejercicios, tareas, notebooks y prácticas realizadas durante mi proceso de formación en programación backend, APIs REST, modelos, vistas, autenticación, templates y análisis básico de datos.

</div>

---

<div align="center">

## Descripción 📌

</div>

<p>
El objetivo de este repositorio es documentar mi progreso aprendiendo desarrollo backend con Python y tecnologías relacionadas.
</p>

<p>
Aquí se encuentran prácticas sobre:
</p>

* Fundamentos de Python.
* Introducción a Django.
* Modelos y administración en Django.
* Vistas basadas en clases.
* Templates en Django.
* APIs REST.
* ViewSets con Django REST Framework.
* Autenticación en Django REST Framework.
* Gráficas y análisis básico de ventas.
* Fundamentos de Linux aplicados al desarrollo backend.

## Contenido del repositorio 📂

</div>

* Análisis y visualización básica de datos de ventas.
* Introducción a los conceptos básicos de APIs REST.
* Práctica sobre ViewSets en Django REST Framework.
* Ejercicios sobre autenticación en APIs con DRF.
* Trabajo con modelos, base de datos y panel de administración.
* Uso de templates para renderizar contenido dinámico.
* Conceptos básicos de Linux y primeros pasos con Django.
* Prácticas conectando backend con frontend.

---

<div align="center">

## Objetivos de aprendizaje 🎯

</div>

<p>
Este repositorio tiene como propósito reforzar habilidades importantes para el desarrollo backend, tales como:
</p>

* Crear proyectos con Django.
* Diseñar modelos de datos.
* Trabajar con bases de datos.
* Crear APIs REST.
* Implementar autenticación.
* Organizar rutas, vistas y serializers.
* Entender la estructura de un proyecto backend.
* Usar Git y GitHub para control de versiones.
* Documentar proyectos de forma profesional.
* Conectar proyectos backend con frontend usando React.
